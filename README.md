# LECO Outage Checker CLI

A command-line application to check power outage information from Lanka Electricity Company (LECO) using your account number. Built with Python, it scrapes the LECO web portal to retrieve and display real-time outage status and customer account details.

## Features

- Quick outage status lookup by account number
- Retrieves customer account details
- Simple command-line interface

## Technologies

- Python
- Requests
- BeautifulSoup4

## Usage
```python
python forLECO.py
```

Enter your LECO account number when prompted (default: 0208066xxx).

## Note

This project was created in 2022. The LECO web portal may have changed since then, so the scraper might need updates to work with the current website structure.
